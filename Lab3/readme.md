## hhtp status codes -> res.WriteHead( ), res.statusCode
- 200 -> OK
- 201 -> Created   ()
- 400 -> Bad request
- 401 -> Unauthorized  (without login)
- 403 -> forbidden  (access parmission nahi hai)
- 404 -> Not Found
- 500 -> Internal server error
